# Pharma Data Analysis Dashboard

## Project Overview
This project analyzes pharmaceutical inventory data using Microsoft Power BI to support inventory monitoring and data-driven decision-making.

## Tools Used
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and KPIs
- Data visualization and dashboard design

## Dashboard Pages
- **Page 1:** Overall inventory performance and key KPIs
- **Page 2:** High-risk inventory monitoring and detailed analysis
- 
## Key Objectives
- Monitor inventory performance using KPIs.
- Identify high-risk inventory items.
- Analyze inventory categories and trends.
- Present actionable insights through interactive dashboards.

## Project File
Open `pharmadata.pbix` using Microsoft Power BI Desktop to explore the dashboard.
